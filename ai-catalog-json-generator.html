AI-CATALOG.JSON GENERATOR

Publish a map of your agentic resources.

Create a minimal ARD manifest for MCP servers, A2A agents, Skills, APIs, nested catalogs, or registries. The generator builds a domain-anchored urn:air: identifier and adds the search metadata discovery services need.

Open the generator →

What the generator includes

  • specVersion: "1.0" and host identity
  • A globally unique, domain-anchored resource identifier
  • An IANA-style artifact media type
  • An HTTPS reference to the underlying artifact
  • A clear description and representative discovery queries

Where to publish

Host the result at https://your-domain/.well-known/ai-catalog.json. Your server should return JSON content and allow cross-origin reads by discovery crawlers.
